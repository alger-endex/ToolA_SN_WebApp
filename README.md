# Tool A SN 站（Web App）

掃描 DRV 的 QR code 取得 SN，經 USB 送到 Tool A 治具（`ToolsA_EbikeDrv`，需含 26B20 PC link 韌體），並記錄每台測試結果。

不需安裝、不需網路、沒有伺服器：用 **Chrome 或 Edge** 開啟 `index.html` 即可（Web Serial API）。

## 檔案

| 檔案 | 說明 |
|---|---|
| `start.bat` | 以 Edge（或 Chrome）App 視窗開啟，建議用這個 |
| `index.html` / `style.css` / `app.js` | 程式本體 |

## 使用步驟

1. 治具 USB 接電腦，**直接上電**（不要按 SW1）→ 電腦出現「USB 序列裝置 (COMx)」。
2. 執行 `start.bat`。
3. 按「連接治具」→ 選清單中的治具（只會列出 VID 0483 / PID 5740）。
4. 掃描器：
   - **USB-COM 模式**：按「連接掃描器 (COM)」選掃描器的 COM。
   - **鍵盤模式**：不用連接，頁面在最前面時直接掃即可（或掃到下方輸入框）。
   - **手機 BLE**：手機開啟「ToolA 掃描」App（`ToolA_ScanApp_Android`），按「連接手機」→ 在清單選這支手機。
5. 第一次使用：展開「設定」填站別；按「選擇 CSV 紀錄檔」指定紀錄檔（每筆結果即時寫入）。
6. 生產：掃 QR → 畫面顯示「治具已接受 SN」→ 按治具 SW1、SW4 → 結果顯示 PASS / Er，並寫入紀錄 → 掃下一台。

授權過的治具、掃描器之後開頁會自動連接；USB 拔插或治具重開機也會自動重連並重送 SN。

## 手機 BLE 掃描

- 瀏覽器（Web Bluetooth）只能當 BLE **主控端**，無法被連接；所以由手機 App 廣播、電腦按「連接手機」去連。連上後資料雙向：
  - 手機 → 電腦：`QR,<內容>`（與掃描器輸入走同一套解析與防呆）
  - 電腦 → 手機：`HELLO,<站別>`、`MSG,<ok|warn|err|info>,<訊息>`、`RES,<代碼>,<說明>,<SN>`，手機同步顯示並震動提示
- UUID：Service `7a0b1000-0d6b-4a43-9a8e-3f1c2b5d0a01`，TX(notify) `…1001…`，RX(write) `…1002…`（與 App 的 `BlePeripheral.java` 一致）。
- 短暫斷線會每 3 秒自動重連（最多約 30 秒）。手機 App 重開或藍牙位址輪換後需重新按「連接手機」。
- 多站同時使用時，請在手機藍牙名稱設定站別（例 `ToolA-L1A`），連線清單才容易辨認。
- 電腦需有藍牙 4.0+（BLE），Windows 10/11，Chrome 或 Edge。

## QR code 內容（自動判斷）

| 格式 | 範例 |
|---|---|
| 純 SN | `EBK2611200000012` |
| 欄位式 | `SN=EBK2611200000012;PN=RD1;HW=02`（`=` 或 `:`，分隔 `; , & |`） |
| 網址 | `https://xxx/p?sn=EBK2611200000012` |
| JSON | `{"sn":"EBK2611200000012"}` |

SN 規則：16 字（寫入 DRV 0x0010–0x0017），英數字、不可有逗號，最後 5 碼為數字。
可在設定加「SN 規則」正規表示式（例：`^EBK2611` 限定前綴），或允許只掃 5 碼流水號。
掃描器的 AIM 識別碼前綴（如 `]Q1`）會自動去除。

## 防呆

- 格式錯誤、不符規則 → 紅字＋錯誤音，不送出。
- 已 PASS 過的 SN → 警告，需確認才送出（設定可關閉）。
- 治具測試中掃描 → 拒絕。
- 治具開始測試時的 SN 與掃描不符、或沒掃描就開始 → 紅字警告；紀錄標示「SN 相符 = N」並以黃色列顯示。
- 每台出結果後清除目前 SN，下一台必須重新掃描。
- 治具忙碌（不在待機）時自動每秒重送 SN，直到治具接受。

## 紀錄

- 每筆存在瀏覽器（localStorage），並可同步寫入指定的 CSV 檔（UTF-8 BOM，Excel 可直接開）。
- CSV 欄位：時間、站別、治具SN、結果、說明、掃描SN、SN相符、條碼原文。
- CSV 被 Excel 開著時會寫入失敗（畫面提示，該筆仍保存在瀏覽器，可再「匯出 CSV」）。
- 重新開啟瀏覽器後，若顯示「需重新授權」，按一下「重新授權紀錄檔」。

## 結果代碼

| 代碼 | 說明 |
|---|---|
| PASS | 測試合格，參數與 SN 已寫入 |
| E1–E9 | 測試錯誤（同治具七段顯示 Er-1~9） |
| W1 / W2 / W5 | 寫治具參數：SIG / 寫入 / 通訊錯誤 |
| P1 / P2 / P5 | 寫客戶參數：SIG / 寫入 / 通訊錯誤 |
| S2 / S5 | 寫 SN：寫入 / 通訊錯誤 |

## 注意

- 同一個 COM 只能被一個程式開啟：使用本頁時請關閉終端機、`toola_logger.py` 等。
- 需要更新治具 config 時，按住 SW1 上電進入隨身碟模式（此時本頁連不到治具，屬正常）。
- 協定定義見 `ToolsA_EbikeDrv/App/Inc/pc_link.h`。
